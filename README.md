# Codex of the Broken Zodiac

An isometric twin-stick roguelike shooter with procedural generation, Lovecraftian themes, and card-based progression built in Godot 4.2.

[![Run on Replit](https://replit.com/badge/github/yourusername/codex-of-the-broken-zodiac)](https://replit.com/github/yourusername/codex-of-the-broken-zodiac)

## Features

- Six psyche-driven classes with unique abilities (Occult Detective, Apostate Medium, Irredeemable Debtor, etc.)
- Twelve Zodiac Sigils that provide unique combat bonuses
- Tarot card-based progression system featuring 78 cards (22 Major Arcana, 56 Minor Arcana)
- Procedurally generated rooms with Lovecraftian visuals and themes
- 1-4 player online co-op multiplayer
- Cross-platform: PC (WASD + mouse) and mobile (virtual sticks) support

## Controls

### PC
- **WASD**: Movement
- **Mouse**: Aim
- **Left-Click**: Fire weapon
- **Right-Click**: Cast spell
- **Mouse Wheel**: Cycle spells
- **E**: Interact
- **Space**: Dodge
- **ESC**: Pause menu

### Mobile
- **Left Virtual Stick**: Movement
- **Right Virtual Stick**: Aim
- **Tap**: Fire weapon
- **Two-finger tap**: Cast spell
- **Swipe up/down**: Cycle spells

## Core Game Elements

### Classes
- **Occult Detective**: Volition-driven class with marksman rifle, rally aura, and interrupt shot
- **Apostate Medium**: Inland Empire-based class with shotgun, astral projection blink, and spirit shield
- **Irredeemable Debtor**: Authority-driven class with gatling cannon and berserk abilities
- **Reclusive Archivist**: Empathy-centered class with beam staff and time manipulation
- **Seditious Orator**: Suggestion-based class with dual pistols and charm abilities
- **Phantom Constable**: Esprit de Corps-based class with revolver and team synergy abilities

### Progression
- **Motes of Insight**: In-game currency for unlocks and upgrades
- **Tarot Cards**: Major and Minor Arcana providing various combat and tactical benefits
- **Zodiac Sigils**: Twelve star signs offering unique combat modifiers
- **Legendary Armor Sets**: Rare equipment with set bonuses and special abilities

## Development

### Requirements
- Godot 4.2
- .NET 8.0 SDK for C# development

### Project Structure
- `Data/`: Contains game resource files (.tres/.res)
- `Scripts/`: C# and GDScript code files
- `Scenes/`: Godot scene files (.tscn)
- `Assets/`: Art, audio, and other assets
- `Tests/`: Unit tests for game systems
